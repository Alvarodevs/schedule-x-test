# schedule-x-test

## Descripción
Este proyecto es una aplicación para gestionar y programar tareas.

## Instalación
Para instalar las dependencias del proyecto, ejecuta el siguiente comando:

```sh
npm install
```

## Uso
Para iniciar la aplicación, ejecuta el siguiente comando:

```sh
npm start
```
